# Проверка версии 0.1.0

Дата: 25 октября 2026 года.

- `npm test`: 4 проверки пройдены — порядок записи, восстановление после перезапуска, отклонение некорректных данных, сохранение повреждённого исходного файла.
- `npm run test:ui`: Chromium — 26 глав, поиск, переход между главами в режиме слайдов, формулы KaTeX, заметки, закладки, сохранение при перезагрузке, безопасное отображение текста заметок, переходы к 8 интерактивным модулям и отсутствие горизонтального переполнения при минимальной ширине окна.
- `npm run test:electron`: настоящий Electron в Linux с Xvfb — запуск, изоляция renderer, IPC и запись на диск, экспорт и импорт, сохранение профиля перед импортом, перезапуск и анимация. Для автоматизации заменены ответы системных диалогов; операции с файлами настоящие.
- Windows x64 portable EXE собран electron-builder. Целостность контейнера NSIS проверена 7-Zip. Основной Windows EXE в комплекте имеет архитектуру x86-64; сам распаковщик NSIS — 32-битный.
- Основной процесс, preload, хранилище, интерфейс и адаптер курса в `app.asar` побайтово совпадают с проверенными исходниками.

Запуск EXE на настоящей Windows 10/11 пока не выполнялся. Подписи издателя нет. Обычный установщик NSIS не выпускается в этой версии; для скачивания предназначен только файл без суффикса `Setup`.

Данные курса перенесены из v3. Эти проверки не являются повторной экспертизой всех математических объяснений и не подтверждают педагогическую эффективность курса. Новые анимации для всех 26 тем и отсроченная проверка знаний остаются планом следующего этапа.
