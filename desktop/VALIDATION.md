# Проверка версии 0.2.1

Дата: 25 октября 2026 года.

Воспроизведён дефект со скриншота пользователя. Правило `.basics math { display:block }` ломало естественную раскладку MathML. Формула масштаба занимала 197 px по высоте; после перехода на заранее сформированный KaTeX — около 43 px, формула скорости — около 53 px. Конфликтующее правило удалено.

- Проверены размеры и скриншоты обеих новых формул при ширине 1100, 700 и 550 px.
- Проверены 26 глав: 73 формулы, отсутствие ошибок рендеринга и горизонтального переполнения страницы.
- Проверены 78 слайдов: 73 формулы, отсутствие ошибок рендеринга и вертикального распадения формул.
- Открыты четыре прежних живых объяснения, ошибок KaTeX не обнаружено.
- Проверены шаги вычисления с ненулевой нижней границей и отрицательной скоростью, ограничения кнопок перехода между шагами.
- Пройдены 7 проверок моделей/хранилища, проверки интерфейса и настоящий запуск Electron в Linux.
- Файлы в Windows-сборке сверяются с исходниками; контейнер EXE проверяется 7-Zip. Сам Windows EXE на настоящем Windows-ПК пока не запускался. Подписи издателя нет.

Эти проверки касаются отображения, контрольных вычислений и поведения приложения. Они не заменяют полную содержательную экспертизу каждой главы курса.

# Проверка версии 0.2.0

Дата: 25 октября 2026 года.

- 7 проверок хранилища и математических моделей: ненулевая нижняя граница датчика, 4 и 20 мА на границах, проценты и процентные пункты, нулевой знаменатель, нагрев/охлаждение/выдержка и среднее через границы участков.

- Windows portable EXE проверяется на целостность и соответствие упакованных исходников. Запуск на настоящей Windows пока не проверен; подписи издателя нет.

# Проверка версии 0.1.0

Дата: 25 октября 2026 года.

- `npm test`: 4 проверки пройдены — порядок записи, восстановление после перезапуска, отклонение некорректных данных, сохранение повреждённого исходного файла.
- `npm run test:ui`: Chromium — 26 глав, поиск, переход между главами в режиме слайдов, формулы KaTeX, заметки, закладки, сохранение при перезагрузке, безопасное отображение текста заметок, переходы к 8 интерактивным модулям и отсутствие горизонтального переполнения при минимальной ширине окна.
- `npm run test:electron`: настоящий Electron в Linux с Xvfb — запуск, изоляция renderer, IPC и запись на диск, экспорт и импорт, сохранение профиля перед импортом, перезапуск и анимация. Для автоматизации заменены ответы системных диалогов; операции с файлами настоящие.
- Windows x64 portable EXE собран electron-builder. Целостность контейнера NSIS проверена 7-Zip. Основной Windows EXE в комплекте имеет архитектуру x86-64; сам распаковщик NSIS — 32-битный.
- Основной процесс, preload, хранилище, интерфейс и адаптер курса в `app.asar` побайтово совпадают с проверенными исходниками.

Запуск EXE на настоящей Windows 10/11 пока не выполнялся. Подписи издателя нет. Обычный установщик NSIS не выпускается в этой версии; для скачивания предназначен только файл без суффикса `Setup`.

Данные курса перенесены из v3. Эти проверки не являются повторной экспертизой всех математических объяснений и не подтверждают педагогическую эффективность курса. Новые анимации для всех 26 тем и отсроченная проверка знаний остаются планом следующего этапа.
