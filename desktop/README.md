# Контур — инженерная школа

Первая desktop-версия для Windows 10/11 x64. Первый раздел — ТАУ с нуля для будущего инженера АСУ ТП. Учебные материалы, формулы, анимации и сохранение прогресса работают без интернета.

[Скачать EXE для Windows 10/11 x64](https://raw.githubusercontent.com/nlpwnz/lab1/tau-desktop-v0.1/downloads/Kontur-Learning-0.1.0-Windows-x64.exe)

## Запуск

Скачайте `Kontur-Learning-0.1.0-Windows-x64.exe`, поместите его в удобную папку и запустите двойным щелчком. Это переносимая сборка: установка, Node.js, Python и отдельный браузер не нужны. При первом запуске распаковка встроенного движка может занять некоторое время. Можно создать ярлык EXE на рабочем столе. Сборка не подписана сертификатом издателя; Windows может показать предупреждение о неизвестном издателе.

## Что уже работает

- 26 глав существующего курса с формулами, примерами и задачами.
- Поиск темы, продолжение с последней главы, закладки и заметки к каждой главе.
- Четыре живых объяснения: производная, интеграл, полюсы, путь сигнала по контуру.
- Четыре лаборатории: бак, инерция, ПИД, частотное поведение.
- Учебник, 78 слайдов и иллюстрированный практикум в PDF.
- Раздельные отметки чтения и правильного ответа на вопрос главы.
- Локальное автосохранение; экспорт и восстановление резервной копии JSON.

Это первая рабочая версия оболочки. Новые анимации для всех 26 тем, расписание повторения и оценка самостоятельного решения ещё не реализованы. Карта будущих опытов: [ANIMATIONS.md](ANIMATIONS.md).

## Данные пользователя

Прогресс хранится в стандартной папке данных приложения, обычно `%APPDATA%\Kontur Learning\progress.json`. Он отделён от каталога установки. Удаление EXE не удаляет профиль автоматически. Перед переустановкой или переносом компьютера используйте **Данные и материалы → Сохранить копию**.

Восстановление требует подтверждения замены. Предыдущий профиль сохраняется в `progress.before-import.json`. Повреждённый файл при загрузке сохраняется в `progress.json.recovery-...`; приложение сообщает об этом и создаёт новый профиль. Копии находятся в той же папке данных.

Приложение не требует аккаунта и не отправляет учебные данные. Внешние источники открываются в системном браузере только по нажатию ссылки. PDF открываются локальной программой чтения. Автообновления нет; новая версия скачивается отдельно.

## Разработка

Требуется Node.js 22.12+ и npm. Версии зависимостей закреплены в `package-lock.json`.

```sh
npm ci
npm start
npm test
npm run build:win
```

Переносимая сборка Windows создаётся в `dist/`. Для обычного установщика предусмотрена команда `npm run build:installer`; её следует выполнять в Windows или в Linux с Wine. По умолчанию сборка ничего не публикует. Интерфейс можно проверить через `npm run test:ui`; нужен Chromium по пути `/usr/bin/chromium` или переменная `CHROMIUM_PATH`. Проверка настоящего Electron: `npm run test:electron`; в Linux нужен работающий X-сервер (например, Xvfb). Тест создаёт временный профиль.

Архитектура: Electron, изолированная оболочка `src/`, локальный курс `content/tau/`, адаптер `desktop-bridge.js`. Файловый доступ находится только в основном процессе, интерфейс использует ограниченный IPC. Встроенный курс не имеет доступа к Node.js. Состояние проверяется по схеме и записывается через временный файл; очередь сохраняет порядок изменений.

Материалы ТАУ перенесены из версии 3 с отдельным адаптером и скрытой старой навигацией. KaTeX включён локально; его лицензия находится в `content/tau/LICENSE-KaTeX.txt`. Источники учебных материалов доступны внутри курса. Материалы сторонних университетских сайтов не перепубликовывались в этой сборке.
