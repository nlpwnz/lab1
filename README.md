# Автономный реестр конвейерных лент

Это локальное приложение для ведения реестра лент, заявок поставщикам, заказов и эскизов траектории. Производственные данные в репозитории отсутствуют.

## Быстрый запуск

1. Скачайте `index.html` через **Code → Download ZIP** или откройте файл на GitHub и нажмите **Download raw file**.
2. Распакуйте архив, если скачивали ZIP.
3. Откройте `index.html` двойным щелчком в Chrome, Edge или Яндекс Браузере.
4. Интернет и учётная запись OpenAI не нужны.
5. Нажмите **Импорт старого HTML** и выберите прежний файл реестра.

Импорт выполняется локально в браузере. Выбранный файл, размеры, чертежи и прочие сведения никуда не отправляются.

## Сохранение и передача

- **Скачать приложение с данными** создаёт новый самостоятельный HTML-файл с текущим реестром.
- **Резервная копия** сохраняет JSON для регулярного резервного копирования.
- **Восстановить JSON** загружает сохранённую резервную копию.
- **CSV для Excel** выгружает основную таблицу.

После изменений передавайте коллегам последний HTML-файл, созданный кнопкой **Скачать приложение с данными**.

## Что есть в приложении

- обзор состояния запасов и заказов;
- редактируемый реестр;
- карточки лент с размерами, профилями, гофробортами и чертежами;
- формирование текста общей заявки поставщику;
- этапы заказов и поставок;
- конструктор траектории с перемещаемыми роликами;
- справочник материалов;
- локальное автосохранение;
- импорт старого HTML, JSON-резервирование и CSV.

## Ограничение

Это автономная однопользовательская версия. У каждого экземпляра HTML своя база. Для одновременной работы нескольких сотрудников с единым реестром потребуется серверная база данных и авторизация.
